# OverTheWire WarGames Walkthrough

A collection of walkthroughs, solutions, and notes for **OverTheWire Wargames**.

## Official OverTheWire

- **Official Wargames:** [OverTheWire Wargames](https://overthewire.org/wargames)
- **Official Bandit:** [OverTheWire Bandit](https://overthewire.org/wargames/bandit)

## Available Wargames

### Bandit

**Status:** ✅ Available

The `bandit/` directory contains solutions and walkthroughs for the Bandit levels.

```text
bandit/
├── level0.md
├── level1.md
├── level2.md
├── ...
└── level33.md
```

Bandit is aimed at beginners and teaches the fundamentals needed to progress to other OverTheWire wargames.
