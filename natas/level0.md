# Natas Level 0 → Level 1

## Topic

View page source

## Objective

Obtain the password required for the next Natas level.

## Solution

Inspect the HTML source of the page. The password for the next level is exposed in an HTML comment.

Useful method:

```text
View Source / Ctrl+U
```

Look through the HTML for comments and other information that is not rendered on the page.

The hidden comment contains the password for `natas1`.

## Key Concepts

This level is primarily about **View page source**.

## Next Level

```text
natas1
```

and continue with [Level 1 → Level 2](level1.md) if that file exists.
