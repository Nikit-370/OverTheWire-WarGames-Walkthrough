# Bandit Level 30 → Level 31

Clone:

```
git clone ssh://bandit30-git@bandit.labs.overthewire.org:2220/home/bandit30-git/repo
cd repo
```

Inspect tags:

```
git tag
```

Then:

```
git show <tag>
```

There is a tag containing the password.

This level is about knowing that information can exist in Git **tags**, not just branches or the working tree. The official challenge confirms the Git repository setup.
