# Bandit Level 33 → Level 34

There isn't a normal Level 34 challenge.

Level 33 is the final Bandit level. The official Level 33 page describes it as the final escape after the Git challenges.

So the progression is:

```
0 → 1
1 → 2
2 → 3
...
31 → 32
32 → 33
33 → FINISH
```

## The commands you should learn from Bandit

If you're doing this to actually learn Linux/CTF skills, pay particular attention to these:
