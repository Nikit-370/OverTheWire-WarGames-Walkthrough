# Bandit Level 27 → Level 28

**Goal:** Clone a Git repository.

From your **local machine**, not necessarily the Bandit server:

```
git clone ssh://bandit27-git@bandit.labs.overthewire.org:2220/home/bandit27-git/repo
```

Enter the Level 27 password.

Then:

```
cd repo
ls
cat README
```

The repository contains the Level 28 password.

The official challenge explicitly says this repository should be cloned from your local machine.
