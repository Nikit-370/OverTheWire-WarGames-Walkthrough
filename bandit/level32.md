# Bandit Level 32 → Level 33

This is the **uppercase shell** level.

The shell changes your commands to uppercase, which normally breaks them.

Try:

```
$0
```

That invokes another shell.

Then:

```
whoami
```

You should have a usable shell.

Now:

```
cat /etc/bandit_pass/bandit33
```

That's the final password.
